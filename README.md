# ring-call-cellular

אפליקציית אנדרואיד שמשנה אוטומטית את **מצב הצלצול** (צלצול / רטט / שקט) ואת **עוצמת הצלצול** לפי שעות וימים בשבוע.

## מה יש בגרסה הזו (MVP)
- יצירה, עריכה, מחיקה והפעלה/כיבוי של כללים (שעות, ימים, מצב, עוצמה)
- כללים שעוברים חצות (למשל 23:00–07:00)
- חפיפה בין כללים: המצב השקט יותר קובע
- מצב ברירת מחדל כשאין כלל פעיל
- תזמון מדויק ב-`AlarmManager`, שממשיך לעבוד גם אחרי הפעלה מחדש של הטלפון
- ממשק בעברית, מימין לשמאל

## התקנה
1. ב-[Actions](../../actions) פותחים את הריצה האחרונה שהצליחה ומורידים את `ring-call-debug-apk`.
2. מחלצים את ה-ZIP ומתקינים את `app-debug.apk` בטלפון. צריך לאשר התקנה ממקורות לא ידועים.
3. באפליקציה מאשרים גישה ל״נא לא להפריע״. בלי ההרשאה הזו אי אפשר לעבור למצב שקט.

## בנייה מקומית
```bash
./gradlew testDebugUnitTest assembleDebug
```
דרישות: JDK 17 ו-Android SDK 35.
