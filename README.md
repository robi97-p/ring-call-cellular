# ring-call-cellular
    תיהיה שליטה על צלצול הנייד ועל הרטט שלו לפי שעות

אפליקציית אנדרואיד (Android 8 ומעלה) לשליטה בצלצול וברטט לפי שעות.

## יכולות
- **שעות שקטות** – בוחרים שעת התחלה ושעת סיום (גם מעבר לחצות), ובזמן הזה הטלפון עובר ל"שקט" או ל"רטט בלבד". בסוף הזמן מצב הצלצול חוזר למה שהיה קודם.
- **נקודה אדומה בשורת המצב** – כל עוד התוכנה מופעלת מוצגת נקודה אדומה קטנה ליד סמל ה‑Wi‑Fi. אפשר להזיז אותה ימינה/שמאלה במסך ההגדרות כדי שתשב בדיוק ליד ה‑Wi‑Fi בדגם שלך. נוסף לכך מוצגת התראה קבועה עם סמל נקודה.
- **שפה** – עברית או אנגלית, בחירה מתוך האפליקציה (לא תלוי בשפת המכשיר).
- **מספרים מורשים** – מספרי טלפון שנרשמים ברשימה עוקפים את ההשתקה: כשמתקשרים מהם הטלפון מצלצל כרגיל, ואחרי סיום השיחה ההשתקה חוזרת. ההשוואה לפי 9 הספרות האחרונות, כך ש‑`050-1234567` ו‑`+972501234567` נחשבים אותו מספר.

## התקנה בנייד המחובר למחשב
1. בנייד: הגדרות ← אודות הטלפון ← לחיצה 7 פעמים על "מספר Build", ואז באפשרויות מפתחים להפעיל **ניפוי באגים ב‑USB**.
2. לחבר את הנייד ב‑USB ולאשר בנייד את המחשב.
3. במחשב (עם [Android platform-tools](https://developer.android.com/tools/releases/platform-tools)):
   ```bash
   adb install -r release/RingCallControl.apk
   ```

## הרשאות שיש לאשר בפתיחה הראשונה
- גישה ל"נא לא להפריע" – כדי להעביר את הטלפון לשקט/רטט.
- הצגה מעל אפליקציות אחרות – בשביל הנקודה האדומה.
- טלפון ויומן שיחות – כדי לזהות את המספר המתקשר (מספרים מורשים).
- התראות (Android 13+).

בחלק מהיצרנים (Xiaomi, Samsung, Huawei) כדאי גם לבטל "חיסכון בסוללה" לאפליקציה כדי שתמשיך לפעול ברקע.

## בנייה מהקוד
```bash
./gradlew assembleRelease
```
הקובץ נוצר ב‑`app/build/outputs/apk/release/app-release.apk`.
